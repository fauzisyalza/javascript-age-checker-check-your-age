#  JavaScript Age Checker - Check Your Age

Simple Age Checker app to calculate your current age based on your birth year.

###  Features
- Input your birth year (example: 2010)
- Calculates age automatically using `new Date().getFullYear()`
- Shows result instantly on the page with `innerHTML`
- Also shows result with `alert()` popup
- Clean and simple UI with centered card layout

### 🛠️ Tech Stack
- HTML5
- CSS3
- JavaScript (Vanilla JS)

###  How to Use
1. Type your birth year in the input (example: 2010)
2. Click the `Cek Usia` button
3. Your current age will appear below the button
